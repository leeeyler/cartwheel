Finish the local setup

From the repository folder, install the project and create its fictional data:

uv sync
uv run python -m seed.generate

Copy .env.example to .env if needed. Add your model provider's API key there, then restart the workbench. Keep the key in that local file.

The app remains available to explore before a key is configured. Live questions become available when the server can call the model.
